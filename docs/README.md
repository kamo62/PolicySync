# Project documentation

Read the [project README](../README.md), then the [implementation plan](implementation-plan.md). The detailed Technical PRD v2.0 is supplied separately and is not included in tracked source or archives.

For offline continuation, use the setup commands in the [project README](../README.md), the implementation plan and [dependency notes](../vendor/README.md). Local handoff and agent instruction files are not part of exported source.

The implementation plan is the canonical delivery tracker; update its statuses and verification evidence as work progresses. Obtain the separately supplied PRD before feature work that depends on its detailed requirements.

The [decision record folder](adr/README.md) explains how to record future architectural decisions. PRD decisions already settled do not need duplicate decision records.

The PRD references earlier product, addendum and business-plan documents which are not supplied in this repository. Their contents have not been independently reviewed. See the plan for assumptions requiring discussion.
